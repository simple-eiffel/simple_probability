Architecture: CLASS HIERARCHY + FACADE PATTERN

Three-Layer Design:
1. DISTRIBUTION (Abstract)
   ├── DISTRIBUTION_CONTINUOUS [pdf, cdf, icdf, sample]
   │   ├── NORMAL_DISTRIBUTION
   │   ├── UNIFORM_DISTRIBUTION
   │   ├── BETA_DISTRIBUTION
   │   └── EXPONENTIAL_DISTRIBUTION
   └── DISTRIBUTION_DISCRETE [pmf, cdf, icdf, sample]
       ├── BINOMIAL_DISTRIBUTION
       └── POISSON_DISTRIBUTION (Phase 1.5)

   ├── BAYESIAN_UPDATER (conjugate prior updates)
   ├── CREDIBLE_INTERVAL (confidence bounds)
   └── PROBABILITY_VALUE (type-safe [0,1] values)

3. FACADE
   └── SIMPLE_PROBABILITY (factory, utilities)

PHASE 1 MVP SPECIFICATION
================================================================================

Scope: 5 Continuous Distributions + Bayesian Basics

Distributions:
1. NORMAL_DISTRIBUTION (mu, sigma)
   - PDF via formula
   - CDF via error function approximation
   - Sampling via Box-Muller transform
   - Contracts enforce sigma > 0

2. UNIFORM_DISTRIBUTION (a, b)
   - PDF = 1/(b-a)
   - CDF = (x-a)/(b-a)
   - Sampling trivial (already uniform)
   - Validates architecture

3. BETA_DISTRIBUTION (alpha, beta)
   - PDF via beta function
   - CDF via incomplete beta
   - Sampling via rejection
   - Conjugate prior for Binomial

4. EXPONENTIAL_DISTRIBUTION (lambda)
   - PDF = lambda * exp(-lambda * x)
   - CDF exact formula
   - Sampling via inverse transform
   - Reliability/waiting times

5. BINOMIAL_DISTRIBUTION (n, p)
   - PMF via binomial coefficient
   - Likelihood for Beta
   - Sampling via inverse transform
   - Discrete; integer-valued

Bayesian Inference:
- BAYESIAN_UPDATER.update_conjugate_beta_binomial(prior_alpha, prior_beta, successes, trials)
  → Returns posterior Beta distribution
  → Exact conjugate update (closed form)
  → No numerical MCMC needed
