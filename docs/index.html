Overview

simple_probability provides type-safe probability distributions and Bayesian inference for Eiffel.

Features: Normal, Uniform, Exponential, Beta, Binomial distributions. Bayesian conjugate priors, credible intervals, posterior estimation.

Part of the Simple Eiffel ecosystem.

Features

  • Multiple distributions: Normal, Uniform, Exponential, Beta, Binomial
  • PDF/PMF, CDF, ICDF, sampling for all distributions
  • Bayesian conjugate priors and credible intervals
  • Design by Contract throughout
  • SCOOP compatible, void-safe
